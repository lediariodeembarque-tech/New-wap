# New Wap — Diário de Embarque

## Executar localmente

```bash
npm install
npm run dev
```

## Fluxo principal

1. Informe um e-mail válido e uma senha na tela de login.
2. No dashboard, pesquise, abra ou adicione um voo.
3. Preencha os dados do voo e as observações.
4. Adicione fotos pela câmera ou galeria em dispositivos compatíveis.
5. Gere o relatório pelo botão **Gerar relatório**.

Os voos e as observações são mantidos no `localStorage` do navegador. A integração com backend ainda depende da definição da API, autenticação e banco de dados do ambiente de produção.
